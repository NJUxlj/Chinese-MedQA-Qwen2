## 使用示例

### 1. **mdagents_usage_examples.py** - 完整功能示例
包含6个详细的使用示例：
- ✅ **基础医疗咨询** - 演示简单的症状咨询处理
- ✅ **复杂病例处理** - 处理多症状复杂病例
- ✅ **不同共识机制** - 展示各种共识算法（简单多数、加权投票、Borda计数、模糊共识）
- ✅ **批量处理** - 一次性处理多个医疗查询
- ✅ **系统监控** - 实时监控系统状态和统计信息
- ✅ **自定义配置** - 使用自定义LLM和共识配置

### 2. **quick_start.py** - 快速入门指南
- ✅ **交互式选择** - 用户可以选择运行不同的示例
- ✅ **基本使用流程** - 4步完成医疗查询处理
- ✅ **多查询演示** - 展示不同复杂度病例的处理

## 如何使用这些示例

### 运行快速入门示例：
```bash
cd examples
python quick_start.py
```

### 运行完整功能示例：
```bash
cd examples
python mdagents_usage_examples.py --mode all    # 运行所有示例
python mdagents_usage_examples.py --mode single # 运行单个示例
```
